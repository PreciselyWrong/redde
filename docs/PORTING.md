# Porting Redde from iOS (Swift) to Android (Kotlin)

The iOS source this port follows is commit **`37a2db7`** of this repository (the last one with the
Swift code). Read any iOS file from it without checking it out:

```sh
git show 37a2db7:Echo/Services/Transport/HermesServeClient.swift
git ls-tree -r --name-only 37a2db7 Echo/
```

`docs/ARCHITECTURE.md` still describes the iOS app; its Connections and Conversations sections
are the protocol spec the transports follow.

## Scope

Phone and tablet parity. Not ported: Apple Watch (Wear OS), CarPlay (Android Auto), home-screen
widgets and Control Center (Glance), the Mac build, AirPods head gestures (no Android API), and
`companion/calendar-mcp` (a Mac-only EventKit server).

## Tests

The iOS tests (`EchoTests/*.swift` at `37a2db7`) are ported with the code they cover: each Kotlin
module's `src/test` keeps the same cases, with the server responses that were inline Swift strings
moved to `src/test/resources/fixtures/` where they are long. The crypto vectors of
`EchoTests/PushTests.swift` were produced by the plugin's `core.py` and must pass unchanged.

## Building without Android

Google's Maven repository and the Android SDK are not reachable from every machine (cloud agents
included). `./gradlew -Predde.jvmOnly=true test` leaves the Android modules out and builds and
tests the `core/*` JVM modules from Maven Central alone.
